# ICU 排班助手

面向 ICU 月度值班安排的浏览器工具。无需安装软件，可导入轮转表、上月班表和二三值班表，辅助完成人员分组、自动排班、约束检查、班次统计与 Excel 导出。

## [立即打开 ICU 排班助手](./ICU排班助手.html)

建议使用最新版 Chrome 或 Edge 浏览器。首次打开后，按照页面顺序导入资料即可开始排班。

## 快速开始

1. **导入当月轮转安排**：读取心胸外 ICU 人员，并在原表包含电话时自动补充联系方式。
2. **导入上月班表和当月二三值班表**：衔接上月末排班，识别二值覆盖、假期和二线人员。
3. **先生成夜班**：检查人员分组、参加排班状态、不可排日期等信息，生成并人工复核夜班草稿。
4. **再推荐白班**：夜班确认后单独推荐白班；系统不会为补白班而改动夜班。
5. **确认例外并导出**：同组、双主/双副、临时主班及紧密衔接须填写原因并人工确认后再导出。

## 主要功能

- 自动提取当月轮转人员及可识别的联系电话
- 按班型、专业背景和综合实力平衡分组
- 支持主班、副班、住院总、二线及二值覆盖安排
- 支持不可排日期、固定周期、上月衔接等明确约束；个人偏好不参与算法
- 支持不安排白班、仅周六白班、周六和周日白班三种模式
- 自动统计总班数及周四、周五、周六、周日等班次分布
- 导出排班表、分组名单和班数平衡明细

## 排班权重与降级规则

- 每人累计质量分控制在平均值约 ±3 范围（对应新版 1–6 权重尺度），HTML 与 Python 使用相同上下限算法。
- 配对先严格要求跨组；严格跨组无解时仅周五、周六可启用同组兜底，并在日表、校验区和导出结果中明确标记、人工复核；周一至周四和周日始终必须跨组。
- 白班在夜班生成后单独推荐，不计入夜班质量分，但计入总工作负荷和周末综合负担；当天或前一天值夜班者不能承担白班。
- 白班候选分为理想、普通和例外；同组、双主/双副、临时主班及紧密衔接需要记录原因并人工确认。
- 夜班质量权重：周一至周三 5、周四 6、周五 4、周六 1、周日 2；周日因补休延后，低于周五。
- 周末综合负担按周五至周日夜班与周六、周日白班共同统计，优先控制个人差值不超过 1。

## Python 求解器

`scheduler_cp.py` 提供与页面一致的 CP-SAT 版本：

```powershell
python -m pip install -r requirements.txt
python scheduler_cp.py --day-shift-mode none
python scheduler_cp.py --day-shift-mode saturday
python scheduler_cp.py --day-shift-mode weekend --output icu_schedule.csv
```

## 使用建议

- 自动结果定位为可复核、可调整的排班初稿，生成后请结合科室实际情况检查。
- 导入资料后，先到“人员与分组”确认姓名、电话、班型和组别是否正确。
- 若原始 Excel 中没有某人的联系电话，系统会保留为空，可在人员编辑区手工补充。
- 浏览器会保存当前项目数据；更换电脑或浏览器前，可先使用“导出项目”备份。

## 数据与隐私

- 上传的 Excel 和排班数据在浏览器本地处理，不会自动上传到 GitHub。
- GitHub Pages 仅提供 APP 程序文件，不包含使用者导入的人员和排班资料。
- 在公共或共用电脑上使用后，建议导出所需结果并清空浏览器中的项目数据。

## 离线使用

需要离线运行时，可下载整个仓库并解压，保持 `ICU排班助手.html` 与 `xlsx.full.min.js` 位于同一文件夹，然后双击 HTML 文件打开。
